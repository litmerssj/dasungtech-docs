## 2. 포함 구성

| 영역 | 구성 | 수량 |
| --- | --- | ---: |
| 앱 서버 | EC2 `t3.large`, 2 vCPU·8GiB | **2대** |
| 앱 디스크 | gp3 50GB | 2개 |
| 로드밸런서 | Application Load Balancer | 1개 |
| DB 서버 | EC2 `r7i.xlarge`, 4 vCPU·32GiB | 1대 |
| DB 디스크 | gp3 1.1TB, 3,000 IOPS·125MiB/s | 1개 |
| DB 엔진 | SQL Server 2022 Standard | 1식 |
| 라이선스 | Standard 4코어 영구 | 1식 |
| 조회 최적화 | 인덱스·캐시·gp3 경량 보강 예산 | 월 0–18만원 |
| 운영 범위 | MISCM·MISTW·MISSA·MISTO·MISPD | 5개 DB |
