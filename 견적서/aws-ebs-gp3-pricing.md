# AWS EBS gp3 저장공간 가격 기준

| 항목 | 내용 |
| --- | --- |
| 작성일 | 2026-08-28 |
| 기준 리전 | AWS 서울 `ap-northeast-2` |
| 볼륨 유형 | General Purpose SSD `gp3` |
| 환율 | USD 1달러 = 1,400원 |
| 원화 표기 | VAT 10% 포함 |

## 1. 적용 단가

| 가격 항목 | 적용 단가 | 비고 |
| --- | ---: | --- |
| gp3 저장공간 | **$0.0912 / GB-월** | ANASA AWS 계정 Cost Explorer 2026-08 청구 사용유형 역산 |
| 기본 IOPS | 3,000 IOPS 포함 | 초과 프로비저닝 시 추가 요금 |
| 기본 처리량 | 125MB/s 포함 | 초과 프로비저닝 시 추가 요금 |

공식 가격은 AWS 가격 페이지에서 리전을 선택해 확인할 수 있다. 본 견적은 ANASA 계정의 서울 리전 실제 `APN2-EBS:VolumeUsage.gp3` 비용과 사용량으로 확인한 $0.0912/GB-월을 적용했다.

- [AWS 공식 EBS 가격](https://aws.amazon.com/ebs/pricing/)
- [AWS 공식 gp3 성능·기본 제공량 설명](https://docs.aws.amazon.com/ebs/latest/userguide/general-purpose.html#gp3-ebs-volume-type)

## 2. 계산식

```text
월 저장공간 비용(세전) = EBS 용량(GB) × $0.0912
월 저장공간 비용(VAT 포함) = 세전 비용 × 1.10
원화 비용 = VAT 포함 달러 × 1,400원
```

## 3. 용량별 EBS 비용

| EBS 용량 | 월 세전 | 월 VAT 포함 | 월 원화(VAT 포함) | 적용 시나리오 |
| ---: | ---: | ---: | ---: | --- |
| 400GB | $36.48 | $40.13 | 약 5.6만원 | 현재 단일 EC2 볼륨 |
| 500GB | $45.60 | $50.16 | 약 7.0만원 | 현재 DB 운영 권장 용량 |
| 750GB | $68.40 | $75.24 | 약 10.5만원 | DB 2배 성장 |
| 1.1TB | $100.32 | $110.35 | 약 15.4만원 | DB 3배 성장 |
| 1.8TB | $164.16 | $180.58 | 약 25.3만원 | DB 5배 성장 |

1.1TB와 1.8TB는 견적 계산에서 각각 1,100GB와 1,800GB로 적용했다.

## 4. 권장 디스크 용량 산정

```text
권장 EBS = 예상 DB 용량 × 1.25 + 시스템 공간 약 50GB
```

| DB 증가 | 예상 DB | 계산상 필요량 | 견적 권장 EBS |
| --- | ---: | ---: | ---: |
| 현재 | 279GB | 약 399GB | 500GB |
| 2배 | 557GB | 약 746GB | 750GB |
| 3배 | 836GB | 약 1,095GB | 1.1TB |
| 5배 | 1.39TB | 약 1,792GB | 1.8TB |

25% 여유는 DB 증가, 트랜잭션 로그, `tempdb`, 인덱스 작업과 운영 중 일시 공간을 위한 것이다. 별도 DB 서버에서는 운영체제, SQL Server, Docker 또는 시스템 로그 공간도 함께 고려한다.

## 5. 비용 변동 조건

| 조건 | 비용 영향 |
| --- | --- |
| EBS 용량 증설 | GB에 비례해 선형 증가 |
| 3,000 IOPS 초과 설정 | 추가 IOPS 요금 발생 |
| 125MB/s 초과 설정 | 추가 처리량 요금 발생 |
| EBS 스냅샷·장기 백업 | 별도 스냅샷 저장 비용 발생 |
| 다른 리전 사용 | 리전별 단가 적용 |
| 환율·VAT 변경 | 원화 환산액 변경 |

현재 견적에는 gp3 기본 성능만 포함하며 추가 IOPS, 추가 처리량, 스냅샷 및 오프사이트 백업 비용은 포함하지 않는다.
