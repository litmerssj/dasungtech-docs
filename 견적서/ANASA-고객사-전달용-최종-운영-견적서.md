# ANASA ERP 운영 인프라 견적서

| 구분 | 내용 |
| --- | --- |
| 견적 기준일 | 2026-08-30 |
| AWS 리전 | 서울 `ap-northeast-2` |
| 환율 | USD 1달러 = 1,400원 |
| 금액 기준 | VAT 10% 포함, AWS 온디맨드 추정액 |
| 데이터 기준 | 현재 약 279GB, 3배 성장 시나리오 |
| 라이선스 기준 | SQL Server 2022 Standard 4코어 영구 라이선스 |

## 1. 고객사 전달용 요약

| 구분 | 금액 |
| --- | ---: |
| **첫해 예상 비용** | **약 2,415만원** |
| **2년 차 이후 월 운영비** | **약 100만원** |
| 2년 차 이후 연 운영비 | 약 1,200만원 |
| 월 확장 예산 상한 | 약 200–300만원 |

| 포함 범위 | 내용 |
| --- | --- |
| 앱 고가용성 | 앱 서버 2대 + 로드밸런서 |
| 조회 최적화 | 일반 수준의 인덱스·캐시·스토리지 보강 |
| DB 운영 | SQL Server Standard, 5개 운영 DB |
| 저장공간 | 현재 용량의 3배를 고려한 1.1TB |

> 본 견적은 **일반 조회 최적화와 앱 서버 이중화를 포함한 권장 운영 예산**입니다. 실제 AWS 청구액은 사용시간, 트래픽, 백업, I/O 및 계약 할인에 따라 달라질 수 있습니다.

## 2. 권장 구성

| 영역 | 권장 구성 | 수량 |
| --- | --- | ---: |
| 애플리케이션 서버 | EC2 `t3.large` (2 vCPU, 8GiB) | 2대 |
| 트래픽 분산 | Application Load Balancer | 1개 |
| DB 서버 | EC2 `r7i.xlarge` (4 vCPU, 32GiB) | 1대 |
| DB 저장공간 | EBS gp3 1.1TB (3,000 IOPS, 125MiB/s) | 1개 |
| DB 엔진 | Microsoft SQL Server 2022 Standard | 1식 |
| SQL 라이선스 | Standard 4코어 영구 라이선스 | 1식 |
| 운영 DB | MISCM·MISTW·MISSA·MISTO·MISPD | 5개 |

## 5. DB 용량 증가 시나리오

| 데이터 증가 | 예상 DB 용량 | 권장 EBS | DB EBS 월 비용 |
| --- | ---: | ---: | ---: |
| 현재 DB (1배) | 279GB | 500GB | 약 7만원 |
| 현재 DB의 2배 | 557GB | 750GB | 약 10.5만원 |
| **현재 DB의 3배** | **836GB** | **1.1TB** | **약 15.4만원** |
| 현재 DB의 5배 | 1.39TB | 1.8TB | 약 25.3만원 |

> 1.1TB는 확정 용량 제한이 아니라, 현재 약 279GB 데이터와 향후 증가분·운영 여유공간을 반영한 예산 기준입니다.
