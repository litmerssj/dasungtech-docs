# SP 원문 근거

아래 코드 블록은 SP 파일에서 하드코딩 후보가 있는 런타임 SQL 본문을 발췌한 것이다. SQL 리터럴과 주석의 업무 의미는 원문 그대로 유지했고, 긴 중간 구간은 `...`로 생략하거나 가독성을 위해 줄바꿈만 정리했다. 전체 파일은 각 항목의 `전체 원문` 링크에서 확인한다.

## 1. 품목·공정 예외 목록

## 원문 미복사 항목

목록의 다음 SP도 동일한 방식으로 하드코딩 후보를 확인했으며, 전체 원문 링크를 제공한다. 공통 패턴을 반복 복사해 문서가 읽기 어려워지는 것을 피했다.

| SP | 화면 | 핵심 원문 패턴 |
| --- | --- | --- |
