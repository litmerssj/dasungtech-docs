# 다성테크 기술 문서

다성테크 ANASA ERP의 클라우드 인프라, 운영 안정성, 비용 및 소프트웨어 라이선스 검토 자료를 관리한다.

## 문서 영역

- [인프라](./인프라/README.md) — 가용성, 단일 장애점, 백업·복구, 클라우드 전환
- [견적서](./견적서/README.md) — AWS 인프라, SQL Server 라이선스 및 비용 옵션

## 문서 원칙

- 확인된 사실과 계획·추정을 구분한다.
- 운영 의사결정은 비용만이 아니라 업무 중단 허용시간(RTO)과 데이터 손실 허용량(RPO)을 함께 기준으로 삼는다.
- 백업은 정기 복원 시험을 통과해야 복구 수단으로 인정한다.
- 운영 전환 시에는 기존 서버와 클라우드 중 한쪽만 쓰기 원본으로 지정해 데이터 분기를 막는다.
