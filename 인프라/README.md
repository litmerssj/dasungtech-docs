## 현재 결론

점검된 스테이징은 프런트엔드를 제외한 핵심 업무 경로가 단일 EC2에 집중돼 있다. 컨테이너 재시작과 배포 롤백은 준비돼 있지만 EC2, EBS 또는 가용영역 장애를 넘는 대체 경로는 확인되지 않았다.

운영 전 최소 조건은 다음과 같다.

1. 회사가 승인한 RTO/RPO
2. SQL Server 네이티브 백업과 별도 저장소 보관
3. EBS/인스턴스 계층 백업
4. 장애 알림과 담당자 호출 체계
5. 새 인스턴스에서 수행한 복원 훈련
6. 클라우드 절체·롤백 절차와 데이터 정합성 검증

적극적인 다중 가용영역 이중화 여부는 “기능 변경 빈도”가 아니라 실제 출고·입고·재고·정산 중단 비용으로 결정한다.
